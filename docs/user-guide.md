# User Guide

## Opening The App
Open `Emergency Services Platform` in Power Apps. Choose the role that matches your task: Volunteer, Coordinator, or Roster Manager.

## Report An Incident
1. Open `Incident Report`.
2. Select the incident type.
3. Select the severity.
4. Use the current location if available, or type a short location description.
5. Add brief notes.
6. Select `Submit Incident`.

The app shows a success message after the report is saved. Coordinators can then view the incident on the dashboard.

## Review Incidents As Coordinator
1. Select the Coordinator role.
2. Open `Coordinator Dashboard`.
3. Review active incidents.
4. Select an incident and update its status.

Use statuses consistently: New, Assigned, In Progress, Resolved.

## Set Volunteer Availability
1. Open `Roster Availability`.
2. Select the date.
3. Select the time slot.
4. Select Available, Maybe, or Unavailable.
5. Add notes if needed.
6. Save the record.

## Log Equipment Checks
1. Open `Equipment & Training`.
2. Choose the Equipment tab or section.
3. Select equipment type and condition.
4. Add notes.
5. Save the check.

## Track Training
1. Open `Equipment & Training`.
2. Choose the Training tab or section.
3. Enter the course or certification name.
4. Select the certification status.
5. Add the expiry date if relevant.
6. Save the record.

## Field Use Tips
- Keep incident notes short and factual.
- Use high severity only when immediate coordinator attention is required.
- Update availability early so roster managers can plan coverage.
- Mark damaged or missing equipment immediately.
